ROTA — LAYOUT RESPONSIVO DE RASTREAMENTO

Esta versão atualiza a composição visual para um cabeçalho compacto, banner promocional ilustrado, área de rastreamento e rodapé amarelo, com adaptação a celulares e desktops.

Identidade e ilustrações próprias. O site não representa os Correios e não coleta CPF, endereço ou dados pessoais. O formulário aceita código de rastreamento alfanumérico e encaminha a consulta ao portal oficial dos Correios:
https://rastreamento.correios.com.br/app/index.php

Estrutura principal:
- index.html
- css/style.css
- images/rota.svg

Para publicar, mantenha a estrutura de pastas. O arquivo js/latest.js e as imagens de origem não são necessários para esta versão e foram removidos do pacote para evitar scripts ou imagens antigas sem uso.
